# SoleVault

O SoleVault será uma plataforma web voltada para pessoas interessadas em tênis e roupas streetwear. A
proposta é reunir produtos em um catálogo organizado, facilitar a pesquisa por marca, categoria, tamanho e
preço, permitir que o usuário salve favoritos e oferecer sugestões de produtos e combinações de looks de acordo
com o estilo e o orçamento informado.
