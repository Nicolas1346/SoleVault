2. Requisitos funcionais revisados

RF01 — Cadastro e gerenciamento de produtos: O sistema deve permitir que o administrador cadastre, edite e exclua tênis e roupas streetwear, informando nome, marca, categoria, preço, tamanho, descrição e imagem.

RF02 — Pesquisa de produtos: O sistema deve permitir que o usuário pesquise produtos pelo nome ou marca.

RF03 — Filtros: O sistema deve permitir filtrar produtos por preço, marca, tamanho e categoria.

RF04 — Detalhes do produto: O sistema deve exibir informações do produto, incluindo nome, marca, imagem, preço, tamanho e descrição.

3. Requisitos não funcionais revisados

RNF01 — A interface deve ser simples e fácil de utilizar.

RNF02 — O sistema deve funcionar nos principais navegadores atuais.

RNF03 — As páginas devem se adaptar a computadores e celulares.

RNF04 — As informações devem ser armazenadas com segurança, utilizando validação no servidor e consultas preparadas no banco de dados.

RNF05 — O sistema deve apresentar as informações de forma organizada e com tempo de resposta adequado.

RNF06 — O código deve ser organizado para facilitar manutenção e futuras melhorias.
